# Changelog

## 0.1.0-alpha.1

Initial public source preview of CosmoEdge Connect.

- Local single-device service for retained-alarm summaries, source-image capture
  for host interpretation, and changes to existing installed algorithms.
- Stdio MCP adapter with explicit business contexts, original artifacts,
  persisted request identity and recovery after interrupted calls.
- Paired WorkBuddy client and Skill, plus macOS and Windows development-package
  builders and installation tooling.
- Local confirmation and device readback for changes, with retained parameters,
  regions and schedules.
- Architecture decisions, troubleshooting guidance, deterministic regression
  fixtures, contribution instructions and third-party license materials.

This is a source preview. Platform and client validation boundaries are listed
in [compatibility](docs/compatibility.md). Release notes link the checks for the
published commit; package and real-device acceptance require their own evidence.
